# Panel de Finanzas — Tarjeta

Panel estático para analizar resúmenes de tarjeta. Procesa PDFs en el navegador y guarda el historial en localStorage.

## Privacidad
Los resúmenes y datos financieros no forman parte del repositorio. El repositorio contiene únicamente el código de la aplicación.

## Uso
1. Abrir el panel.
2. Adjuntar el PDF del resumen.
3. El resumen queda guardado en el navegador.
4. Para mover el historial a otro dispositivo: Exportar datos en el dispositivo origen e Importar backup en el destino.

## Comparaciones
Con dos o más meses cargados aparecen automáticamente la evolución y la variación porcentual mensual.
